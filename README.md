# The World in One Picture — Monday 23 November 2026

A newspaper infographic that sums up Monday 23 November 2026 in one image:
**40 stories, 7 regions, 10 fields — every one first reported that Monday.**

The program draws the whole page itself (Node 22, standard library only):
a serif masthead, a "THE DAY IN UTC" timeline, a "THE DAY IN NUMBERS" strip,
6 featured stories with scenes drawn for each, 15 more stories with small
illustrations, a "WHERE IT HAPPENED" world map with numbered pins, an
"ALSO ON 23 NOVEMBER" list, a DATE CHECK box, and a sources footer. Every
story carries a verification label (CONFIRMED / OFFICIAL / REPORTED / CLAIM /
FORECAST) and its news source.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program writes `out/entry.png` (1024×1024 PNG). It runs twice with
byte-identical output and needs no network.

## Stories

Sources include AP, Reuters, AFP, Xinhua, Zacks, Bloomberg, MIT News, CNA
and Middle East Eye. Headlines: COP31 collapses with no deal after 48 hours
of overtime; Democrats clinch a House majority of at least 258 seats; Trump
"inclined" to resume conflict with Iran if no deal is reached by New Year;
Russian strikes kill 11 in the Kyiv region; Liverpool 4–0 Manchester United;
a candy factory fire in Indonesia leaves 24 dead and about 30 missing — and
34 more stories from the same day.
